# Time Table Planner

A C-based Time Table Planner that generates a weekly timetable while detecting conflicts between subjects, faculty, rooms, and student batches.

## Features

- Add and manage courses/subjects
- Manage faculty and classrooms
- Manage time slots
- Detect timetable conflicts
- Use graph coloring concepts for scheduling
- Generate a clash-free timetable
- View the generated timetable
- Web interface for displaying timetable information

## Technologies Used

- C
- Data Structures and Algorithms
- HTML
- CSS
- JavaScript
- Makefile

## DSA Concepts Used

- Structures
- 2D Arrays
- Graph Coloring
- Conflict Graph
- Hashing
- Backtracking
- Greedy Optimization
